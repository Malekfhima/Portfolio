## Brand & Style
The design system positions Malek Fhima at the intersection of high-scale full-stack architecture and hardware-level IoT/embedded engineering. The aesthetic conveys precision, telemetry, and low-latency execution. 

Drawing from **Glassmorphism** overlaid on a **Futuristic/High-Contrast Dark Theme**, the UI evokes an advanced mission-control terminal or telemetry interface. Frosted dark-glass surfaces, micro-glow borders, and high-frequency code monospaces command respect from engineering leads, founders, and deep-tech recruiters. Motion and depth feel weighted, tactile, and luminous without slipping into generic cyberpunk tropes.

## Colors
The palette relies on a deep cosmic hierarchy designed for sustained focus and visual weight:
- **Neutral canvas (`#0A0F1F`)**: Deep space navy acts as the foundational void. Elevated panels transition into obsidian-tinted navy (`#0E162B`) and elevated midnight translucent layers.
- **Electric Cyan (`#00D4FF`)**: Primary accent used for primary interactive states, key metrics, active routes, and high-priority terminal signals.
- **Cyber Violet (`#7C3AED`)**: Secondary accent denoting full-stack architecture, complex back-end operations, and multi-threaded processing.
- **Luminous Emerald (`#10B981`)**: Dedicated strictly to active IoT sensor telemetry, online states, healthy node pings, and availability indicators.
- **Text & Foreground**: Pure high-contrast white (`#F8FAFC`) for headings, steel mist (`#94A3B8`) for body prose, and muted slate (`#475569`) for subtle metadata and inactive circuit traces.

## Typography
Typography reflects precision engineering. Three distinct type families partition cognitive tasks:
- **Headings (Space Grotesk)**: Geometric, technical quirks provide forward-looking distinction for titles, milestone metrics, and key project anchors.
- **Prose (Inter)**: Clean, neutral, high-density legibility for architectural case studies, project narratives, and technical explanations.
- **Data & Telemetry (JetBrains Mono)**: Explicitly reserved for code snippets, memory allocations, circuit baud rates, pinout manifests, and UI micro-badges. All label elements must use uppercase formatting with widened letter spacing (`0.08em` to `0.1em`).

## Layout & Spacing
The layout adheres to a 12-column responsive fluid grid structured for technical showcases:
- **Desktop (1200px+)**: 12 columns, 1.5rem gutters, and 3rem exterior safe margin with a max container width of 1360px.
- **Tablet (768px - 1199px)**: 8 columns, 1.25rem gutters, 2rem canvas margin. Multi-column hardware schematics reflow to 4-column stacked blocks.
- **Mobile (<768px)**: 4 columns, 1rem gutters, 1.25rem canvas margin. Interactive circuit graphs and code previews scroll horizontally within encapsulated viewports.

Vertical rhythms scale on an 8pt step system. Element clustering within cards strictly maintains `space-sm` (8px) or `space-md` (16px), whereas systemic sections pull apart at `space-xl` (40px) to give critical projects breathing room.

## Elevation & Depth
Depth is modeled through physical optics and luminous luminescence rather than generic drop shadows:
- **Ground Floor**: Base surface `#0A0F1F` with a faint CSS radial gradient of 15% opacity `#7C3AED` locked to the canvas header.
- **Glassmorphism Panels**: `background: rgba(14, 22, 43, 0.65)` layered with `backdrop-filter: blur(16px)` and `-webkit-backdrop-filter: blur(16px)`.
- **Neon Glow Outlines**: Card and modal borders leverage a 1px solid stroke of `rgba(0, 212, 255, 0.15)`. On hover, transition the stroke to `rgba(0, 212, 255, 0.45)` coupled with a low-spread outer glow: `box-shadow: 0 0 24px -4px rgba(0, 212, 255, 0.25)`.
- **Active Node Depth**: Floating hardware chips and IoT status widgets carry an underglow cast in emerald: `box-shadow: 0 0 16px -2px rgba(16, 185, 129, 0.3)`.

## Shapes
A balanced roundedness (`roundedness: 2`) offsets the sterile technical tone:
- Base components (inputs, interactive chips, code blocks) adopt `0.5rem` (8px) corners.
- Large contextual surfaces (project feature cards, telemetry containers, modal wrappers) utilize `rounded-lg` (1rem / 16px).
- Status pills, hardware availability indicators, and interactive micro-tags take fully rounded stadium/pill silhouettes to contrast against sharp interior typography.
- Avoid 0px brutalist edges to prevent the system from looking unfinished.

## Components

### Buttons
- **Primary Cybernetic**: Solid Electric Cyan background (`#00D4FF`), deep navy text (`#0A0F1F`), JetBrains Mono bold label. Subtle hover bloom: `box-shadow: 0 0 20px rgba(0, 212, 255, 0.4)`.
- **Ghost Shell**: 1px border `rgba(0, 212, 255, 0.3)`, transparent glass fill, cyan text. Active press scales down slightly (`0.98`).
- **Telemetry Action**: Secondary tone with Cyber Violet accents (`#7C3AED`) reserved for architectural diagrams and deep-dive schema downloads.

### Status Chips & Badges
- **IoT Node Pulse**: Luminous Emerald (`#10B981`) text on `rgba(16, 185, 129, 0.1)` pill background, bordered with `rgba(16, 185, 129, 0.3)`. Prefixed with an animated pulsing dot representing real-time ping.
- **Tech Stack Badges**: JetBrains Mono label-sm, muted slate glass fill (`rgba(255, 255, 255, 0.04)`), crisp 1px hair outline (`rgba(255, 255, 255, 0.08)`).

### Glassmorphic Project Cards
- Crafted with midnight glass (`rgba(14, 22, 43, 0.7)`), 16px blur, and 1px border `rgba(255, 255, 255, 0.08)`.
- On cursor proximity or hover, the border dynamically lights up to electric cyan (`#00D4FF`) with a directional 20px ambient radial glow.

### Form Inputs & Terminal Command Line
- Form inputs feature a dark cavity (`rgba(5, 8, 18, 0.8)`), inset hairline border, and JetBrains Mono typing state.
- Focus state activates an electric cyan glow line and replaces standard placeholder text with a blinking console caret (`_`).

### Code Blocks & Telemetry Feeds
- Top chrome bar with simulated hardware connection pins and filename tab.
- Integrated JetBrains Mono syntax highlighting using Cyan (`#00D4FF`), Violet (`#A78BFA`), and Emerald (`#34D399`) against deep black glass (`#060A14`).
